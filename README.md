# 1911 Grip Customizer

Browser-based customizer for designing 1911 grip panels ([1911.html](./1911.html)), Beretta 92FS grip panels ([92fs.html](./92fs.html)), PMAG 30 magazine panels ([pmag.html](./pmag.html)), and die-cut sticker keychains ([keychain.html](./keychain.html)) — add, arrange, and export image, text, and shape layers over a printable shape outline (or, for keychains, an STL traced around the artwork), entirely client-side. [index.html](./index.html) is the landing page that links to all four editors and can route a previously exported project .zip to the right one.
